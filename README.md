# Prabal Bhandary

Full-stack developer based in Kathmandu. I build production web apps — mostly for Nepal-facing products, where "done" means it actually handles NPR, local time zones, and eSewa/Khalti, not just Stripe and USD.

**Stack I reach for by default:** Next.js (App Router) · MongoDB/Mongoose · NextAuth · Tailwind · Redux Toolkit

---

## What I've been building

**CineVerse** — movie streaming/downloading platform. Next.js 14, MongoDB, NextAuth with Google OAuth. Custom video player, admin analytics dashboard, dark glassmorphism UI.

**BloomStudio** — florist e-commerce platform. Next.js App Router, MongoDB, Redux Toolkit for cart/checkout state, NextAuth for user accounts.

**ÉLARA** — wedding planning marketplace: venues, dresses, jewelry, photographers, invitations, all in one booking flow.

**BusTrack** — live bus tracking. React Native (Expo) app on the front end, Next.js dashboard and API behind it.

**MediCore** — hospital management system for Nepal-based hospitals; multi-module, multi-role.

More on my [repos](https://github.com/prabalbhandary?tab=repositories).

## Notes on how I work

- Ship complete features, not scaffolding — auth, validation, and error handling included by default, not bolted on later
- Prefer boring, well-understood tools over trendy ones unless there's a real reason to switch
- If a product targets Nepal, currency formatting and payment gateways are a first-class concern, not an afterthought
